# otosu

落として、当たって、光って、鳴る。

落ちてくるボールが線や図形に当たって音を鳴らす、生成音楽のビジュアル作品です。
楽器が弾けなくても感覚的に音楽を作れて、プロジェクターで投影したときに映えることを目指しています。

## 開発

```bash
npm install
npm run dev
```

```bash
npm test   # 物理の決定論性・すり抜けなしのテスト
```

## 操作

| 操作 | 内容 |
|---|---|
| ドラッグ | 線を引く（長いほど低い音） |
| 右クリック | 近くの線を消す |
| C | 線を全部消す |
| F | フルスクリーン |
| H | UI とヒントを隠す（投影用） |

右上の `otosu` パネルで BPM、放出口の周期比、回転、発光、残像、音と光のずれ（`visualOffsetMs`）を調整できます。
