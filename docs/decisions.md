# 設計の判断

otosu で決めたことと、その理由。コードのコメントは「decisions.md D3」のようにこの番号を指す。
後の判断で変わったものは、どこで変わったかを書いてある。

## 時刻と物理

### D1 物理は 120Hz
- `stepsPerBeat = 7200 / BPM`。よく使う BPM でステップが拍に割り切れる
- 音のタイミングの精度は、物理の細かさではなく D3 の予約で出す

### D2 論理座標は 1920×1080・y 下向き・px
- 物理はいつも同じ大きさの世界で動くので、ウィンドウの大きさで結果が変わらない
- 線の長さから音程を決めるときも、この論理幅に対する比を使う（余白への配置は D23）

### D3 時計は音（AudioContext）が主、描画はそれに合わせる
- 物理は音の時刻から進める量を決め、少し先行して進む。衝突の発音時刻は `t0 + step / 120` で、ステップ単位なのでリズムが揺れない
- 描画は「今の時刻（renderStep）」の世界を、物理の履歴から補間して見せる。当たった瞬間に光り、同時に鳴る

### D4 発音と発光は 1:1
- 鳴らす・光らせるの判定は物理（sim）だけが行う。sim が出したイベントは必ず鳴って必ず光る
- 弱すぎる衝突や、同じ図形への続けざまの衝突は、イベントを出さない（例外は D11）

### D5 線の最小長は 58px（論理幅の 3%）
- 線の長さから音程を決める範囲の下限に合わせる。短すぎる線は確定させない

### D6 定数と音程の関数を sim に置く
- 音と描画（色）が同じ関数・定数を使う。音程は線を作った時点で決める（D9 で改訂）

### D7 衝突イベントの型
- `HitEvent` に step（時刻の唯一の基準）・ボール・図形・位置・速さ・velocity（音量と光の強さに共通）を持たせる。型は `src/sim/types.ts`

### D8 遅れからの復帰と、時計を 1 本にすること
- 1 フレームで進める物理には上限を置き、大きく遅れたら基準を取り直して飛ばした時間は捨てる（タブの復帰や GC の停止の対策）
- 予約に間に合わなかったイベントは、音も光も捨てる（D4 を守る）
- 時刻はすべてネイティブの AudioContext の `currentTime` を基準にする。Tone の先読みは使わない
- 描画の要素（ボール・線・発光）は、すべて renderStep がイベントの step に達してから反映する
- 放出は整数のステップの格子にそろえる。入力は論理座標に直してから扱う
- 長い線ほど回転を遅くする（端が速くなりすぎてボールがすり抜けないように）

### D9 線に固定するのは音程のスロット
- 線には音程のスロット（0..15）と色だけを固定し、実際の音高はそのときの和音の区間で決める（D48 の曲の進行に従わせるため）
- 描画は sim の図形を直接見ず、イベントから自分用のコピーを持つ（sim と描画の時刻がずれているため）

## MIDI

### D10 MIDI の出力と録音
- Web MIDI で外へ送る（Mac では IAC Driver 経由で DAW へ）。note on は内蔵音が聞こえる時刻に合わせて予約する
- 録音は衝突を step で記録し、Standard MIDI File（フォーマット 0）で書き出す。Web MIDI のないブラウザでも使える。開始は次の拍の頭にそろえる
- 放出の時刻は基準から整数周期を掛けて求める（足し合わせると誤差がたまり、録音が格子からずれるため）
- OSC は見送った。ブラウザから UDP を送れず、中継のサーバーが要るため
- 描画用の時刻をなめらかにするため、AudioContext を自分で作って Tone に渡す（Tone が作るものは `getOutputTimestamp` を持たなかった）

## 図形と音

### D11 D4 の例外
- 置いたときの確定音、描いている途中のティック、和音の持続音（hum）は、入力へのフィードバックや曲らしさのための音なので、光と 1:1 にしない。MIDI にも送らない
- 同じスロットの線がほのかに光る「共鳴」は、光だけ

### D12 図形 = 同じ group を持つ線分の集まり
- 1 本の線も辺が 1 つの図形として扱う。音程・回転・削除・衝突のクールダウンは図形ごと
- 図形の音程は周の長さで決める。角で隣り合う 2 辺に同時に当たっても 1 回だけ鳴る
- 道具は 線・ペン・円・三角・四角。保存形式は v2（v1 も読める）

### D13 バンパー
- 反発係数 1.2 の図形。速さには上限を置き、画面の外へ飛び続けないようにする。音と光は普通の図形と同じ規則

### D14 契約の変更
- 図形単位のイベント（`shapeAdded` / `shapeRemoved` / `shapePose`）と、和音の区間が変わる `section` イベントを足した。衝突には連鎖（chain）と盛り上がり（energy）を載せる

### D15 担当の範囲
- 物理・音・映像・統合の担当でファイルを分け、並行して作れるようにした（今は記録として残している）

### D16 形で楽器が決まる
- line = ベル、pen = はじく音、circle = キック〜タム、triangle = 金属、square = 木。楽器を選ぶ操作を増やさず、形を見れば音がわかるようにする
- 光も形で性格を変える（1:1 は保つ）

### D17 キックを拍にそろえる → D22 で取りやめ
### D18 保存形式に形（forms）を足す
- 無い・壊れているときは形から推定する。古い保存データも読める

### D19 円と四角は GM ドラムとしてドラムのチャンネルへ送る
- DAW でドラムの音色に割り当てやすいように。旋律の図形は今までどおり音高で送る

### D20 担当（D16〜D19 の実装の割り振り。今は記録として残している）
### D21 当たった後に拍の頭でこだまを返す → D22 で取りやめ

### D22 円も当たったら 1 回だけ鳴らす
- 当たって鳴る手ごたえを優先した。くり返しは、図形ごとのエフェクト（D32）として選べるようにした

## 画面と操作

### D23 図形を置ける範囲をウィンドウ全体に広げる
- 16:9 の世界は上寄せにし、余白にも描ける。描いた位置がそのまま置かれる位置になる
- 置ける範囲は固定の範囲でクランプするので、ウィンドウによらず結果が同じ

### D24 UI の整理と、配置・設定の保存
- 操作は画面上端の帯に収め、世界に重ならないようにする。止まって 2 秒で隠れる（タッチでは隠さない）
- 配置（図形・テンポなど）と、この端末の設定（音量・光・MIDI など）を分けて保存する。会場で合わせた設定が、配置を読み替えても変わらないように
- 配置は自動保存・名前を付けて保存・ファイル（`.otosu.json`）・URL で共有できる
- iOS では click で音を始める（pointerdown では鳴らせないため）

### D25 衝突で蔦が伸び、花が咲く
- 見た目だけの効果で、sim と音には関わらない。花は 3D の花びらで、咲く・散る・落ちる
- 花びらはインスタンスで描き、形や動きは咲いた時刻から頂点シェーダで決める（CPU は毎フレーム書き換えない）
- WebGPU には移さない。後処理を全部書き直すことになり、古い端末では WebGL2 に落ちるため

### D26 スマホでは寄って表示し、線を太く描く
- 世界全体を収めると小さすぎるので、タッチの端末では寄る。太さは見た目だけで、当たり判定と音は変えない

### D27 重い端末では自動で画質を下げる
- 重いのは後処理なので、MSAA → 後処理の解像度の順に下げる。インスタンスのバッファは書いた範囲だけ送る
- `?fps` で fps と画質の段階を表示する（上げ直しは D67）

### D28 花が重なって濁らないようにする
- 咲いている花のそばには新しい花を咲かせない。落ちる花は暗くして奥へ退かせる

### D29 音の時計で画面が止まらないようにする
- 毎フレームは `currentTime` だけを読み、performance.now でなめらかにする（`src/audio/clock.ts`）。`getOutputTimestamp` は音声スレッドのロックを待つことがあるため

### D30 再生と停止 → D50 で止め方を変えた

### D31 当たった図形から光が垂れる（drip）
- 残像を自前のパス（`src/render/flow.ts`）にして、明るいところだけを少しずつ下へ流す

### D32 図形ごとのエフェクト（echo / rise / chord）
- 当たったあとの振る舞いを図形ごとに 1 つ選べる。くり返しは sim が決めるので決定論的
- DAW のディレイでは作れない音なので、MIDI と録音にも全部送る
- 図形を長押し（右クリック）して開くメニューから選ぶ。道具を持ち替えずに済むように
- 付いているエフェクトは、図形のまわりの輪郭の動きで見分けられる

## 背景と当たった点の表示

### D33 背景の種類を切り替えられるようにする
- 背景は種類ごとに 1 つの層（`src/render/backdrop.ts` が切り替える）。最初の caustics は、光の格子をうねる面で曲げた模様

### D36 当たった点の計器の表示（readout）

### D37 色は白黒だけ

### D44 三角・四角も、当たると同じ形の輪郭が広がる

## 音

### D58 音の途切れを減らすため、出力のまとまりを大きくする
- `latencyHint` を `playback` にし、sim の先行を 100ms にした。音は先に予約しているので、遅れは描画と MIDI の時刻合わせで吸収される
- `?latency=` で実機で比べられる
### D59 聞こえない音は鳴らさない・声部の横取りでプツッと鳴らさない
- 横取りするときは、音量を 5ms で下げてから高さを変える

### D60 花の種類を選べるようにする（ひまわり・彼岸花・デイジー・花畑）
- 種類ごとに形・色・咲き方・散り方を `SPECIES`（`src/render/flowers.ts`）にまとめる

### D61 全体の音量を上げ、始める前に音量の注意を出す
- 始めたときは各口の最初の 1 回を出さない（全部の口が同時に出して重なるため）
- 読み込んだ図形には確定音を鳴らさない（確定音は人が置いたことを知らせる音なので）

## 配布とプラットフォーム

### D70 動画の録画ボタン
- iPhone の画面収録で録ると、Web Audio の音が雑音になる（Safari 側の問題で、この作りでは直せない）
- キャンバスと出力の音を MediaRecorder でまとめて録る。端末の画面収録を通らないので雑音にならない。映るのは絵だけで、UI は映らない
- 保存はタッチの端末では共有シート、それ以外はダウンロード

### D71 初めての人への案内
- 開始画面に一行の説明を足し、初めての端末でだけ、最初の 1 本を描くまで画面の下に案内を出す

### D72 始めの配置と背景
- 始めの配置は三角・円・四角と線 2 本にし、どの図形にも 5 秒以内に当たるようにする（形で音色が変わることも伝わる）。テストで確かめる
- 背景の既定は ascii

### D73 既定のテンポは 60 BPM
- 始めの配置では光がチカチカしすぎたため

### D74 PWA にする
- オフラインで開けて、ホーム画面や Dock から入れられる。会場でネットなしで投影するため
- アプリにする方法（Electron / Tauri / Capacitor）とも比べた。WKWebView は Web MIDI がないので、まずは PWA にした
- Service Worker は依存を増やさず自前で書く（`src/pwa/sw.js`）。ページはネットを先に見て、3 秒で返らなければ手元のものを返す
- iPhone のホーム画面版は、Safari と保存（localStorage）が別になる

### D75 スマホのスピーカー向けに低音を落として持ち上げる
- 内蔵スピーカーは低音を鳴らせないのに、コンプとリミッターがその低音で効いていたため。タッチの端末では 250Hz より下を切って +9dB する
- `?speaker=1` / `?speaker=0` で上書きできる

### D76 タブが隠れても鳴らし続ける
- BGM として流しておけるように。隠れている間は `setInterval` で sim を進めて音を予約する
- ページを離れるとき（pagehide）だけ止める。iPhone の Safari は裏に回ると JS ごと止まるので、鳴り続けない

### D77 grain の粒は画面の広さに合わせて大きく・明るくする
- 粒の数が一定なので、広い画面ほど薄く見えたため。まず大きくし、足りない分を明るくする
