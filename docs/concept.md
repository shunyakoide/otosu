# otosu — コンセプトと決定事項

> 初期の構想（ステップ1 の時点）。以降の変更と現行の仕様は [design/decisions.md](design/decisions.md) が優先する。

落ちてくるボールが図形に当たって鳴る、音と光の生成音楽作品。
楽器が弾けなくても感覚的に音楽を作れて、プロジェクター投影で映えることを目指す。

## 決定事項

| 項目 | 決定 |
|---|---|
| リズム | **方式A: 決定論的物理**。放出は BPM 同期、物理は固定タイムステップ。同じ配置なら毎回同じ軌道 → 自然に周期パターンが生まれる。量子化はしない（音と光の完全一致を優先） |
| 音程 | 図形の **長さ・大きさ** で決まる（長い／大きい → 低い）。スケール固定（ペンタトニック） |
| 音量 | 衝突速度 |
| 展開 | 放出口を **複数**（周期をずらしてポリリズム）。図形の回転は **オン/オフ可能** |
| 発音数の制限 | まず作ってみて判断（必要ならクールダウン・同時発音上限・ボール寿命） |
| 技術 | Vite + TypeScript + **素の Three.js**（UnrealBloomPass / AfterimagePass）+ **Tone.js**。React / R3F は使わない。調整 UI は自前の小さなパネル（当初は lil-gui。D24 で置き換え） |
| 物理 | 自前実装（ボール vs 線分の反射のみ、ボール同士は衝突しない）。Matter.js は使わない |
| 連携 | できる範囲でシンプルに。まずは Web MIDI（Mac の IAC Driver 経由で DAW へ） |

## ステップ1（MVP）の範囲

- 1画面・黒背景・フルスクリーン
- 上部に放出口 1〜2個、BPM に合わせてボールを落とす
- ドラッグで線を引く／右クリックで消す
- 衝突 → 線の長さで決まるペンタトニックの音 ＋ 線とボールが発光
- 固定タイムステップの自前物理、発光と残像、Tone.js

**合格基準:** 線を5本引いて5分間放置し、心地よく聴いていられること。

**やらないこと:** MIDI/OSC、カメラ、スマホ操作、図形の種類の追加。

## ロードマップ

1. 落ちて・当たって・光って・鳴る最小版
2. スケール・発光・残像で気持ちよさを詰める
3. MIDI（→ 余力で OSC 中継）出力
4. 必要になれば Syphon / Ableton Link のためにネイティブ化（Unity + Keijiro 系プラグインが有力）
